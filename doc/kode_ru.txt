ЧТО ЭТО
-------
KODE - многооконный текстовый редактор для Sprinter в духе старых
редакторов TASM/Borland IDE: строка меню, перекрывающиеся текстовые
окна, контекстная подсказка в статусной строке, поддержка мыши и
настраиваемая подсветка синтаксиса. Ориентирован на исходные тексты
(ассемблер Z80, C, Pascal, BAT-файлы, makefile), но работает с любым
простым текстом.

Программа работает под DSS в текстовом режиме 80x32 (16 цветов).
Нужна клавиатура PS/2; мышь необязательна, но рекомендуется.


БЫСТРЫЙ СТАРТ
-------------
1. Распакуйте архив в каталог, например C:\KODE\. Для работы нужны
   KODE.EXE и подкаталог SYNTAX\ (профили подсветки; без него редактор
   тоже работает - подсветка просто отключится).

2. Запустите KODE.EXE. Чтобы сразу открыть файл, передайте его имя:

     KODE.EXE MAIN.ASM
     KODE.EXE B:\PROJECT\MAIN.ASM

   Если файла нет, Kode откроет пустое окно, привязанное к этому
   имени: первое сохранение создаст файл.

3. Экран: сверху строка меню (F10 или Alt+буква открывает её, работает
   и щелчок мыши), снизу статусная строка с клавишами и контекстной
   подсказкой, между ними - рабочий стол с окнами текста.

4. Настройки хранятся в KODE.SET рядом с KODE.EXE; записываются
   командой Options -> Save setup и читаются при запуске.


ФАЙЛЫ
-----
Одновременно можно держать открытыми до 15 текстовых окон; каждое окно
вмещает около 32 КБ текста. Максимальная длина строки - 240 символов.

KODE.EXE           программа
KODE.SET           ваши настройки (создаётся командой Save setup)
SYNTAX\            профили подсветки (INDEX.LST + *.SYN)
KODE_RU.TXT        это руководство
KODE_EN.TXT        руководство по-английски
FILE_ID.DIZ        описание архива
VERSION.TXT        версия релиза

Open (F3) показывает файловый диалог: введите имя или маску в строке
Name либо выберите файл в списке Files (Enter заходит в подкаталог,
".." поднимается выше). Кнопки:

  Open     открыть файл в НОВОМ окне
  Replac   загрузить файл в ТЕКУЩЕЕ окно, заменив его текст
  Import   открыть и конвертировать файл в новом окне

Стиль конца строки файла (CRLF, LF или CR) определяется при загрузке 
и сохраняется при записи; символы TAB раскрываются в 4 или 8 пробелов
по настройке Tab width.

При каждом сохранении прежняя версия файла остаётся как резервная
копия: её имя строится заменой последнего символа расширения на '_'
или добавлением '_', если расширение короче трёх букв
(MAIN.ASM -> MAIN.AS_, TEST.CC -> TEST.CC_, TEST.C -> TEST.C__).
Без расширения '_' заменяет последний символ имени.

           List... (Alt+0)

Буква, выделенная цветом (в исходниках обозначена ~X~) - горячая
клавиша пункта меню.


КЛАВИШИ РЕДАКТОРА
-----------------
Стрелки              перемещение курсора
Home / End           начало / конец строки
PgUp / PgDn          страница вверх / вниз
Ctrl+Left / Right    предыдущее / следующее слово
Ctrl+Up / Down       прокрутка текста на строку
Ctrl+Home / End      начало / конец текста
Ctrl+PgUp / PgDn     горизонтальная прокрутка страницы
Ctrl+Backspace       удалить слово
Ctrl+Y               удалить строку
Ins                  режим вставки / замены
Del                  удалить символ; с выделенным блоком - удалить его
Tab / Shift+Tab      табуляция вперёд / назад (до поля метки -
                     Label Tab size, дальше - Tab size)
Enter                новая строка (отступ слева сохраняется)

Выделение блока:
Shift+Up / Down      расширить выделение на строку
Shift+Home           начало блока - в позиции курсора
Shift+End            конец блока - в позиции курсора
Alt+Esc              снять выделение

Буфер обмена (общий для всех окон):
Ctrl+X               вырезать блок    Shift+Del   вырезать с добавлением
Ctrl+C               копировать блок  Ctrl+Ins    копировать с добавлением
Ctrl+V               вставить        Del         удалить блок

Опции диалогов Find/Replace: учёт регистра, только слова целиком,
область (весь текст / выделенный), направление (вперёд / назад),
начало поиска (от курсора / вся область) и "Labels only" - искать
только в поле метки (до позиции Label Tab). Replace дополнительно
даёт "Prompt on replace" и кнопку RepAll - заменить всё без вопросов.

Русская раскладка: два Shift вместе переключают язык; в статусной
строке появляется "rus". Shift+Space включает русскую раскладку,
Shift+Enter - латинскую.


ОКНА
----
F5                 развернуть окно на весь экран / обратно
F6 / Shift+F6      следующее / предыдущее окно
Alt+F3             закрыть окно

Refresh display перерисовывает экран.


СБОРКА И ЗАПУСК
---------------
Каталогом проекта считается каталог файла активного окна (для
безымянного нового файла - текущий каталог DSS).

Build (F9)          если есть BUILD.BAT, выполняет
                    "SYSTEM.EXE /C BUILD.BAT"; иначе при наличии
                    MAKEFILE запускает "MAKE.EXE".
Run (Ctrl+F9)       если есть RUN.BAT, выполняет
                    "SYSTEM.EXE /C RUN.BAT" с параметрами сеанса;
                    иначе запускает "MAKE.EXE run", если в MAKEFILE
                    есть цель "run:".
Parameters...       строка, добавляемая к RUN.BAT в этом сеансе
                    (до 64 символов; к MAKE.EXE не добавляется).
Target...           показывает список явных целей MAKEFILE и
                    запускает "MAKE.EXE <цель>". Присваивания
                    (имя:=...), шаблоны (%), имена с '$' и '-'
                    в список не попадают.
Show console log    сохранённый текстовый экран с выводом дочерней
                    программы (а до первого запуска - консоль, какой
                    она была при старте Kode); возврат - любое новое
                    нажатие клавиши.

Если файлы изменены, перед запуском Kode спросит о сохранении.
Ненулевой код завершения показывает "Exit code N - press any key" и
ждёт клавиши; код 0 возвращает в редактор сразу. Обратите внимание:
оболочка SYSTEM.EXE из DSS завершает обработку BAT с кодом 0, поэтому
надёжный код возврата дают программы EXE, например MAKE.EXE.


ПОДСВЕТКА СИНТАКСИСА
--------------------
Подсветкой управляют профили в SYNTAX\ рядом с KODE.EXE. INDEX.LST
сопоставляет расширения файлов (или имя без расширения, как
"makefile") профилю, например "asm.syn=asm,z80,tas,inc,s". Если в
INDEX.LST совпадения нет, Kode пробует SYNTAX\<расширение>.SYN
напрямую. В комплекте профили для ассемблера, C, Паскаля, BAT и
makefile.

Профиль - обычный текстовый файл, его можно править и писать свои:

  case_sensitive=0|1
  line_comment=;            (до 3 символов; начало строчного комментария)
  line_comment2={           (для Паскаля включает также блочные
                             комментарии {...} и (* *)
  string_delims="'          (символы, открывающие строковые литералы)
  brackets=()[]<>           (подсвечиваемые скобки)
  keywords=слово1,слово2,...  (группа 1, например инструкции)
  keywords2=слово1,слово2,... (группа 2, например регистры)

Цвета всех элементов экрана, включая группы подсветки, настраиваются
в Options -> Colors.


НАСТРОЙКИ
---------
Options -> Editor...

  Insert mode           вставка символов вместо замены
  Overwrite blocks      вставка блока затирает текст, а не раздвигает
  Syntax highlight      подсветка при вводе и просмотре
  Truncate line         табличное редактирование: курсор не привязан
                        к набранному тексту и ставится в любое место
                        строки шириной до 240 знакомест
  Keyboard              A - qwerty / B - dvorak
  Auto hidden mouse     прятать указатель мыши при вводе
  Optimal tabulation    при сохранении заменять ведущие пробелы на TAB
  Label Tab size        позиция табуляции поля метки
  Tab size              позиция табуляции поля команд
  Tab width             TAB считается 4 или 8 пробелами при импорте

Options -> Colors...  выбор группы (Desktop, Browser, Dialog window,
                      Text window, Syntaxis, Miscellaneous), затем
                      элемента, затем цвета текста и фона.

Options -> Save setup записывает всё в KODE.SET рядом с KODE.EXE;
файл читается автоматически при следующем запуске. Это обычный
текст - его можно править вручную.


ПРИМЕЧАНИЯ
----------
- Print / Printer setup, Run -> Call debugger и разделы Help -
  заглушки в этой версии.
- Отмены действий (Undo) нет: удаление блока необратимо (буфер обмена
  хранит последний вырезанный/скопированный блок до следующего).
- Без каталога SYNTAX редактор работает, просто без подсветки.
